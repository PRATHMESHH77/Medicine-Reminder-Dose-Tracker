MEDICINE REMINDER & DOSE TRACKER (JAVA)

WHAT IT DOES
- Add tablets and syrups
- Display medicine details and remaining doses
- Record doses with validation
- Show a reminder using a thread
- Show a simple report using Runnable
- Save medicine data to a text file
- Create a byte-stream backup

SYLLABUS CONCEPTS DEMONSTRATED
- Classes and objects
- Default, parameterized and copy constructors
- Constructor overloading
- this keyword
- Encapsulation with private fields and getters/setters
- Array of objects (Medicine[])
- Inheritance and method overriding
- Abstract class and abstract methods
- Interface
- Method overloading and runtime polymorphism
- Packages and access modifiers (public, private, protected, default)
- Exception handling: try, catch, finally, throw, throws, custom exception
- Multithreading using Thread and Runnable; start() and join()
- Character streams: FileReader, FileWriter, BufferedReader, BufferedWriter
- File class
- Byte streams: FileInputStream and FileOutputStream


IMPORTANT
This is an educational tracker. It displays user-entered schedules and does not send real phone notifications or provide medical advice. Enter only the dose schedule given by a qualified healthcare professional.
- Multilevel inheritance is demonstrated by ExtendedReleaseTablet extending Tablet, which extends Medicine.
- ReminderService implements two interfaces, showing that Java classes can implement multiple interfaces (Java does not allow extending multiple classes).
- To add the special tablet type, enter "Extended Release" as the tablet type.
